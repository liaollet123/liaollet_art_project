LIA / OL / LET 콜라주에 섞을 소스 사진을 시선별 폴더에 넣는다(lia, ol, let).
작품을 엮을 때마다 이 폴더에서 무작위로 1~3장을 골라, 크기·자리·각도·세기를 달리해 섞는다.
폴더가 비어 있으면 public/artists/<시선>/ 의 사진을 대신 쓴다.

파일 이름 앞부분이 섞는 방식이다.
  screen-이름.jpg      검은 바탕의 빛·입자·빛줄기 사진. 어두운 곳은 사라지고 빛만 얹힌다(OL 빛번짐 등)
  multiply-이름.jpg    흰 바탕의 먹·그림자·낙서·종이 사진. 밝은 곳은 사라지고 어두운 결만 얹힌다(OL 잉크 손자국, LIA 잎 그림자 등)
  overlay-이름.jpg     색과 결을 덧입힌다(LET 색 젤, 필름 질감 등)
  soft-light-이름.jpg  더 옅게 덧입힌다
  normal-이름.png      투명 배경 PNG(오려 낸 조각)나 그대로 붙일 사진
  (앞부분 없음)        시선의 색으로 보정해 사진 조각처럼 섞는다

권장: 긴 변 1600~2400px, jpg 는 품질 85 이상, 오려 낸 조각은 투명 PNG.
넣은 뒤 npm run dev / build 를 다시 하면 목록(lib/collage-sources.js)이 새로 만들어진다.
